Install open32plus

Open firmware for Baofeng DMR radios, installed from this page over the programming cable. Based on RadioFoundry. MIT licensed.

This browser can't reach the programming cable. Use Chrome or Edge on a desktop computer.

3 DMR voice

DMR voice needs the AMBE+2 codec, which open32plus can't include. Installing erases the codec in the radio, so choose Baofeng's own firmware file for the , one of the versions below. This page reads the codec out of it on this computer, and this browser keeps it for next time. FM, CW and everything else work without it.

4 Install

  1. Plug the programming cable into the computer and the radio.
  2. Click Connect and choose the cable's port.
  3. Switch the radio off. Hold and switch it on: that is update mode. Let go of the keys.

Keep this tab open and in front until it says Installed (a few minutes). Don't minimize the window, switch tabs or let the computer sleep: Chrome slows a page it can't see, and the radio gives up waiting. This page keeps the screen on while it installs. If an install stops, switch the radio back into update mode and install again.

Good to know

		
    
			
  • Nothing in the radio changes until the radio has answered in update mode and the erase starts. Your
			channels, contacts and calibration aren't in the area it erases.
    • 
			
  • If an install stops halfway, the radio won't start, but update mode still works: hold the same keys at
			power-on and install again.
    • 
			
  • Afterward, Menu → Settings → My radio → About shows the build you installed.
    • 
			
  • This page sends nothing anywhere. It needs the internet only to load.
